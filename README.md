# AI Reliability Engineering Course

Лабораторні та research-таски з курсу fwdays **AI Reliability Engineering**.

Кожна лабораторна — окрема директорія з `LAB.md` та скріншотами. Усе розгортання виконується на власному homelab-кластері (Talos + FluxCD, Cilium, Traefik, cert-manager, Ollama як LLM-бекенд).

## Структура

- [Lab1](Lab1/LAB.md) — Розгортання Basic Agentic Infrastructure (agentgateway + kagent)
- [Lab2](Lab2/LAB.md) — Agentic Dashboard, MCP та GitOps-агенти (abox, MCP-сервери, KMCP, GitLessOps)
